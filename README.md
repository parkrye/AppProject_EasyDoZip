# EasyDoZip

광고 · 데이터 수집 없는 안드로이드 파일 관리 · 압축 앱. 폴더 탐색 · 파일 작업, zip 압축 · 해제(암호 지원), 간단한 파일 미리보기를 한 앱에서. 파일은 기기 밖으로 나가지 않음.

## 기능

| 영역 | 내용 |
|---|---|
| 파일 탐색 | 시스템 폴더 선택 화면으로 폴더 추가, 이름 · 크기 · 수정한 날짜 정렬(폴더 우선, 숫자 자연 정렬), 숨김 파일 보기 |
| 파일 작업 | 다중 선택, 복사 · 이동, 이름 바꾸기, 삭제, 새 폴더, 공유 |
| 압축 | 여러 파일 · 폴더를 zip 하나로, 선택하면 AES-256 암호 |
| 해제 | 모두 풀기 · 선택 항목 풀기, 압축 파일이 있는 폴더 또는 직접 고른 폴더로 |
| 압축 파일 보기 | 내부 폴더 탐색, 파일 하나 미리보기 · 다른 앱으로 열기, zip 안의 zip 열기 |
| 암호 zip | ZipCrypto · AES 풀기, AES-256 압축 |
| 미리보기 | 이미지 · 텍스트 · PDF는 앱 안에서, 오디오 · 비디오 등은 다른 앱으로 |
| 진행률 | 압축 · 해제 · 복사 · 이동 진행률 표시 · 취소 |

### 지원 범위

- zip만 지원(저장 · Deflate 방식, 4GB 넘는 ZIP64 읽기). **7z · rar · tar · gz는 지원하지 않음**
- 한국어 Windows에서 만든 zip(CP949 파일 이름) 자동 인식
- `../` 같은 위험한 경로가 든 항목(zip slip)은 풀지 않고 건너뜀
- 암호 zip에서도 파일 이름 목록은 암호 없이 보임(zip 형식 특성)

## 설치

[Releases](../../releases)에서 `EasyDoZip-<버전>.apk`를 받아 설치. Android 8.0 이상.

- 처음 설치 시 "출처를 알 수 없는 앱" 설치 허용 필요. Play 프로텍트가 검사 화면을 띄울 수 있음
- 업데이트는 새 APK를 같은 방식으로 덮어 설치. 추가한 폴더 · 설정 유지
- 앱 안 업데이트 알림 없음. Releases 페이지에서 직접 확인
- 서명 인증서 SHA-256: `f16af4368ee3e278e5c4f8c9bc30e576fee9b92c13aad8124267e8b8a58b284f`
  (`apksigner verify --print-certs EasyDoZip-<버전>.apk`로 확인)

## 개인정보

- **인터넷 권한 없음.** 수집 · 전송하는 데이터 없음. 계정 · 광고 · 사용 통계 · 오류 보고 없음
- 저장소 권한도 요청하지 않음. 사용자가 시스템 폴더 선택 화면에서 고른 폴더 · 파일에만 접근
- 앱이 저장하는 것은 설정 · 추가한 폴더 목록뿐 (Android 클라우드 백업도 끔)
